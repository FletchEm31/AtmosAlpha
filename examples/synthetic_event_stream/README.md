# Synthetic Event Stream Example

This directory is reserved for a public, non-operational demonstration of event-stream validation and append-only capture.

The planned example will use entirely generated events and fictional identifiers to illustrate:

- Required-field and schema checks
- Monotonic sequence validation
- Timestamp sanity checks
- Duplicate detection
- Structured validation errors
- Append-only JSONL-style records

No real feed, venue connection, credential, production capture logic, or private data will be included.
