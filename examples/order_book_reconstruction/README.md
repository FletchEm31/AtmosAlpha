# Order-Book Reconstruction Example

This directory is reserved for a public, non-operational snapshot-plus-delta reconstruction demonstration.

The planned example will use synthetic data to show:

- Snapshot initialization
- Ordered incremental updates
- Sequence-gap handling
- Quantity and price invariants
- Empty-level removal
- Best-bid / best-ask calculation
- Deterministic reconstruction from a recorded fixture

It will not contain a live connector, real market identifiers, trading logic, order management, or proprietary implementation details.
