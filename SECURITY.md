# Security Policy

## Reporting a concern

If you believe this public repository contains an exposed credential, private information, or another security-sensitive issue, do not open a public issue and do not publish the material elsewhere.

Instead, contact the repository owner privately through the GitHub profile associated with this repository and include:

- The affected file or URL
- A concise description of the concern
- Steps to reproduce or verify the issue, if relevant
- Whether the material appears to require immediate removal or rotation

## Scope

This repository contains public, sanitized portfolio material only. It does not include production access, live credentials, deployment configuration, or live execution functionality.

Reports related to proprietary private systems should be handled privately and should not be disclosed publicly.
